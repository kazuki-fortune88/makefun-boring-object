# The Most Boring Object, Reviewed in One Line

[![make.fun](https://make.fun/badge/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3.svg)](https://make.fun/c/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3)

One line, 103 characters, reviewing the dullest everyday object: the dustpan.

## The line

> The dustpan: one job — pick up dust — and it still leaves a thin line of dust behind every single time.

Why this one: the joke comes from how the dustpan really behaves. Its entire
job is picking up dust, and every dustpan on earth still leaves that thin line
of dust behind on the floor, every single time. The object's own dullness — one
job, done badly forever — is the joke.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` writes exactly one line to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
